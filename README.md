# 计图期末大作业

### Random Spawner 使用说明

**设置参数**

- **Prefab**：要生成的物体
- **GrassRoot**：生成物体的父级
- **Total Count**：生成数量（默认100）
- **Spawn Radius**：生成半径（默认10）
- **Min Distance**：最小间距（默认1）

**生成物体：**

1. 设置好Prefab和GrassRoot
2. 调整参数
3. 在Inspector中右键脚本 → **Spawn Objects**

**清除物体**：

右键脚本 → **Clear All**

**注意事项**

1. 只在编辑模式下工作
2. 绿色圆圈显示生成范围
3. 搭载这个脚本的GameObject必须和要放置物体的平面一个高度
